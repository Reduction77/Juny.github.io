# 朱朱白白🍓 · 个人主页

原生 HTML、CSS、JavaScript 静态网站。头像为站长提供的大红花，粉紫色动态光晕、轨道与星点构成鸣潮氛围灵感背景，不包含官方角色立绘。

## 部署到 GitHub Pages

仓库：`Reduction77/Juny.github.io`。将本目录文件上传到仓库根目录，然后在 Settings → Pages → Build and deployment 选择 **Deploy from a branch**，分支 **main**、目录 **/(root)** 并保存。

默认地址为 https://reduction77.github.io/Juny.github.io/ （该仓库属于项目站点；只有 Reduction77.github.io 仓库才对应根域名）。支持后续绑定自定义域名。

无构建依赖，所有资源均为相对路径。外部 Google 字体加载失败会回退到系统字体。页面包含入场动画、可暂停背景、减少动态效果设置、QQ 联系弹窗及复制、五个项目说明、博客/托管/Wiki 入口、友链占位。

修改链接与项目文案：`index.html`；主题：`style.css`；交互：`app.js`；头像：`assets/avatar.jpg`。友链到位后，用真实链接卡片替换 `.friend-placeholders`。
